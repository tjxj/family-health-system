# 个人健康管理系统 · 完整设计文档（V1）

> **文档用途：**本文档是搭建「个人健康管理系统」的完整设计与施工依据，覆盖系统架构、内容模块、Base 表结构、Skills、默沙东结合方式、问诊闭环、定时任务、数据迁移和分期验收。
> **覆盖范围：**本人、大女儿（8 岁）、小女儿（2 岁）。老人/配偶后续扩展。
> **版本：**V1 · 2026-10-14

# 一、系统定位与设计原则

## 1.1 一句话定位

以**豆包**为执行与推理入口、以**飞书**为健康资产底座、以**默沙东诊疗手册大众版**为权威科普来源，为全家搭建一套覆盖「日常—周期—长期」的健康记录、解读、存档与提醒系统，让每一次看病都有准备、有记录、有跟进。

## 1.2 设计原则

1. **记录零负担：**拍照、语音、一句话即可，不填表单；结构化工作由豆包完成，消息卡片确认后才写入。
2. **数据一处沉淀、多种视角：**所有健康数据进同一个 Base，按人、按时间、按指标、按待办分别建视图。
3. **解读必带来源：**医学科普优先引用默沙东大众版，AI 解读只用于理解报告，不替代医生诊断。
4. **异常必闭环：**每个异常指标都要有「复查/就诊/观察」的明确去向，到期自动提醒。
5. **先跑通、再扩展：**先覆盖已有数据的 3 人，老人、配偶在场景真实出现后再纳入。

# 二、整体架构与数据闭环

## 2.1 四层架构

| 层级 | 组成 | 职责 |
|-|-|-|
| ① 输入层 | 拍照 / 语音 / 文字：报告、药盒、症状、体征、饮食 | 随手采集，不需要打开任何独立 App |
| ② 能力层 | 豆包 6 个健康 Skills + 默沙东大众版（知识层） | 解读、分诊、用药核对、问诊摘要、周期小结、科普检索 |
| ③ 资产层 | 飞书 Base（10 表）、文档、云盘、知识库、日历、健康群 | 结构化数据、原始件、解读报告、提醒与共享 |
| ④ 时间层 | 日常 · 周期 · 长期 | 决定每个模块的触发频率与留存方式 |

## 2.2 数据闭环

> 随手记录 → 豆包解读/分诊（引用默沙东）→ 卡片确认 → 写入 Base / 云盘 → 异常自动建复查与提醒 → 诊前生成摘要 → 就诊录音 → 诊后提取医嘱与用药 → 新报告再入库 → 月度/年度复盘

# 三、三层内容模块设计

## 3.1 日常层（随时 / 每天）

| 模块 | 触发场景 | 记录内容 | 产出物 |
|-|-|-|-|
| **报告解读存档** | 拿到化验单、检查单、体检报告 | 全部指标、参考范围、异常项、机构与诊断、原始件 | 解读文档 + 指标入 Base + 原始件入云盘 + 复查计划 |
| **症状日记** | 本人或孩子出现不适 | 症状、起止时间、严重度、诱因、伴随症状、夜间情况 | 症状时间线，供分诊与问诊调用 |
| **用药记录** | 开始吃药、停药、买药 | 药品、成分、剂量、频次、饭前饭后、起止、效果 | 用药时间表 + 用药史 |
| **过敏管理** | 蒿草花粉季、鼻炎发作 | 发作日期、症状程度、用药（喷雾/口服）、缓解情况 | 逐年过敏档案 + 季节备药提醒 |
| **体征与饮食** | 测体温/血压/体重；吃饭拍照 | 体温、血压、体重、心率；饭菜热量与营养 | 体征曲线、饮食记录 |

## 3.2 周期层（周 / 月 / 季 / 年）

| 模块 | 频率 | 内容 | 产出物 |
|-|-|-|-|
| 复查提醒 | 按医嘱（1–2 周等） | 复查项目、关注指标、科室 | 日历事件 + 到期提醒 |
| 年度体检 | 每年 1 次 | 体检报告入库、指标追加、趋势更新 | 趋势看板更新 |
| 疫苗接种 | 按接种程序 | 疫苗、剂次、接种日期、不良反应 | 接种档案 + 下剂次提醒 |
| 专科检查 | 半年/年 | 牙齿、眼科等 | 检查计划 |
| 季节备药 | 花粉季前 2 周 | 备药、清理鼻腔喷雾 | 备药提醒 |
| 月度健康小结 | 每月 1 日 | 上月生病次数、用药、异常未闭环项 | 月度小结文档 |

## 3.3 长期层（跨年 / 终身）

| 模块 | 内容 | 价值场景 |
|-|-|-|
| 终身健康档案 | 每人一份，报告/就诊/用药按时间线挂在人名下 | 问诊、急诊、买保险 |
| 指标纵向趋势 | 尿酸、血脂、血糖、血常规等重点指标逐年曲线 | 识别临界与走势，体检 App 无法跨机构对比 |
| 疾病/手术/住院史 | 既往诊断、手术、住院及时间 | 医生判断病情 |
| 家族健康史 | 直系亲属慢病、肿瘤、确诊年龄、已故原因 | 评估本人与孩子风险 |
| 年度健康总结 | 年初生成上年总结、风险画像与新年目标 | 长期健康管理 |

# 四、飞书 Base 详细设计（10 张表）

> 指标数据采用「长表」结构：一行 = 某人某次某指标，便于无限追加与趋势统计；宽表（指标为行、日期为列）通过视图与仪表盘呈现。原有看板数据按第十节方案迁移。

## 4.1 表 1：members（家庭成员）

| 字段 | 类型 | 选项 / 说明 |
|-|-|-|
| member_id | 自动编号 | 系统生成 |
| 姓名 | 文本 | 本人 / 大女儿 / 小女儿 |
| 关系 | 单选 | 本人 / 女儿 / 配偶 / 父亲 / 母亲 |
| 性别 | 单选 | 男 / 女 |
| 出生日期 | 日期 | 用于年龄计算（儿童参考范围随年龄变化） |
| 血型 | 单选 | A / B / O / AB / 未知 |
| 过敏史 | 多行文本 | 本人：蒿草过敏、过敏性鼻炎；药物过敏记录 |
| 慢病/基础病 | 多行文本 | 无则留空 |
| 备注 | 文本 | 其他需长期记住的信息 |

## 4.2 表 2：reports（报告档案）

| 字段 | 类型 | 选项 / 说明 |
|-|-|-|
| report_id | 自动编号 | 系统生成 |
| 报告人 | 关联 members | — |
| 报告类型 | 单选 | 血常规 / CRP / 尿常规 / 肝功 / 肾功 / 血脂 / 血糖 / 甲功 / 影像 / 体检套餐 / 其他 |
| 报告日期 | 日期 | 采样/检查日期 |
| 机构 | 文本 | 如：儿童医院 |
| 科室 | 文本 | 如：急诊科 |
| 临床诊断 | 文本 | 报告上的诊断，如：急性支气管炎、呕吐 |
| 标本类型 | 文本 | 如：末梢全血 |
| 原始报告 | 附件 | 照片/PDF |
| 云盘链接 | 超链接 | 归档路径 |
| 解读文档链接 | 超链接 | 飞书解读文档 |
| 异常项数 | 数字 | — |
| 状态 | 单选 | 待解读 / 已解读 / 需复查 / 已闭环 |

## 4.3 表 3：lab_indicators（指标库 · 长表）

| 字段 | 类型 | 选项 / 说明 |
|-|-|-|
| 记录ID | 自动编号 | — |
| 报告人 | 关联 members | — |
| 关联报告 | 关联 reports | — |
| 指标名称 | 单选 | 预设常用指标（血白细胞、血红蛋白、血小板、尿酸、肌酐、空腹血糖、总胆固醇、低密度脂蛋白胆固醇等），可随时新增 |
| 指标类别 | 单选 | 血常规 / 尿常规 / 肝功 / 肾功 / 血脂 / 血糖 / 甲功 / 其他 |
| 数值（文本） | 文本 | 保留原文，如「 「这是【姓名】的【报告类型】报告，请逐项提取指标、单位、参考范围与异常标记；按【异常概览 → 关键正常指标 → 逐项解读 → 风险分层 → 复查建议 → 就诊沟通要点】生成解读文档；医学科普引用默沙东大众版对应页面并附链接；解读完成后把指标写入 Base 指标库、报告建档，原始件存云盘，需要复查的建计划。所有写入前发卡片给我确认。」

**用药核对：**

> 「这是【姓名】正在吃的几种药，请识别通用名与成分，核对是否有成分重复、相互作用或禁忌（参考默沙东药物指南），排出按早中晚、饭前饭后的用药时间表，并写入用药记录。」

# 七、默沙东大众版结合设计

## 7.1 五个嵌入点

| 嵌入点 | 具体做法 | 输出 |
|-|-|-|
| 症状自助分诊 | 按症状定位默沙东症状页（如儿童发热、头痛、气短、呕吐） | 红旗症状清单 + 居家观察条件 + 护理 |
| 报告科普引用 | 异常指标对应疾病页（如缺铁性贫血、过敏性鼻炎、肺炎） | 「这是什么、要不要紧」的通俗解释 |
| 用药核对 | 查药物信息指南：成分、禁忌、相互作用 | 多药混吃排查结果 |
| 问诊问题清单 | 查「医生如何诊断和治疗」章节 | 该问医生的问题（检查、方案、复查） |
| 家庭知识库 | 高频页面抓取存档到飞书知识库 | 离线可查、全家共享 |

## 7.2 引用规范

- 统一标注「科普来源：默沙东诊疗手册大众版」，附页面完整 URL，不转述为无来源结论。
- 默沙东内容用于「理解与准备」，不据此自行诊断、停药或换药。
- 网页内容由豆包浏览器读取并留存链接；常用页面可周期性更新存档。

# 八、问诊场景闭环（诊前—诊中—诊后）

| 阶段 | 动作 | 产物 |
|-|-|-|
| **诊前** | 对豆包说「准备问诊」：自动汇总病情时间线、历史异常、用药、过敏史；查默沙东了解诊断与治疗 | 一页纸病情摘要（含 50 字极简口述版）+ 问题清单 |
| **诊中** | 手机展示摘要，避免临场回忆；开启豆包录音 | 就诊录音 |
| **诊后** | 对豆包说「整理就诊录音」：提取诊断、医嘱、用药、复查时间 | 就诊记录 + 用药计划 + 复查/日历提醒；新报告入库 |

**问诊摘要提示词：**

> 「我准备带【姓名】去【科室】看【症状/问题】。请汇总：本次病情时间线、相关异常指标、近期用药、过敏史与既往史，生成一页纸摘要和 50 字口述版；再根据默沙东相关内容，列出该向医生确认的问题（要不要做某项检查、有哪些治疗方案、多久复查）。」

# 九、定时任务与提醒清单

| 任务 | 执行时间 | 动作 |
|-|-|-|
| 检查计划扫描 | 每天 09:00 | 扫描 checkup_schedule，当天/到期事项发提醒 |
| 月度健康小结 | 每月 1 日 09:00 | 汇总上月数据，生成小结 |
| 年度体检提醒 | 每年固定月（如生日月前 1 个月） | 提醒预约体检 |
| 蒿草过敏季备药 | 花粉季前 2 周 | 提醒备药、检查喷雾余量 |
| 年度健康总结 | 每年 1 月 | 生成上年总结与新年目标 |

> 蒿草花粉季的具体起止时间以当年郑州花粉监测为准，搭建时先检索确认后再设定时任务，避免写死日期。

# 十、数据迁移方案

## 10.1 现有数据盘点

- **本人三期体检：**2024-05-15、2025-08-12、2026-07-23，含血常规、尿常规、甲功、血糖、肾功、肝功等约 50 项（来源：现有「体检化验指标纵向对比看板」Base）。
- **大女儿：**2026-09-11 血常规 + CRP + MP-IgM（急性支气管炎，EOS# 1.15 偏高），已有解读文档。
- **小女儿：**2026-09-15 血常规 + CRP（呕吐，中性粒升高），已有解读文档。

## 10.2 迁移步骤

1. 新建独立 Base 与 10 张表、视图（按第四节）。
2. 写脚本读取旧看板 Base：宽表转长表，逐人逐期逐指标写入 lab_indicators，参考范围与异常状态一并迁移。
3. 依据两份已有解读文档，补建 reports、encounters、medications 记录与云盘目录。
4. 迁移后抽样核对：三期指标数量、关键数值（尿酸 378.3 / 428.7 / 405.6）、异常项数。
5. 旧看板保留不删，作为迁移核对的备份。

# 十一、实施分期与验收标准

## 11.1 V1：底座 + 数据（预计 1–2 小时）

- 新建 Base、10 张表与全部视图、仪表盘；建云盘目录。
- 完成三期体检与两份孩子报告的数据迁移。

**验收：**10 表字段齐全；尿酸三期数值与趋势正确；两份报告可在档案中查到；旧看板保留。

## 11.2 V2：核心 Skills（预计半天）

- report-reader、medication-check、symptom-triage 三个 Skills 上线，接入 msd-reference 引用。

**验收：**发一份报告可自动生成解读并写入 Base；拍药盒可完成成分核对；问症状可输出红旗/居家判断并附默沙东链接；写入前均有确认卡片。

## 11.3 V3：闭环与自动化

- visit-brief、health-review 上线；定时任务启用；家族史与年度目标补齐。

**验收：**问诊可出摘要、诊后录音可建用药与复查；到期自动提醒；月度小结自动生成；年度总结可产出。

# 十二、边界与免责声明

- 系统所有 AI 产出仅用于健康信息整理、报告理解与就诊准备，**不构成诊断、处方或用药建议，不替代医生面诊**。
- 出现红旗症状（高热不退、呼吸困难、精神萎靡、剧烈腹痛、意识异常等）立即就医，不依赖线上判断。
- 用药开始、停用、换药、调整剂量均以医生意见为准。
- 健康数据属个人敏感信息，Base 与文档按最小可见范围设置权限；分享前先脱敏。
- 科普内容以默沙东页面原文为准并留存链接；解读与页面不一致时以页面和医生意见为准。
