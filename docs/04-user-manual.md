# 二、3 个最常用动作（90% 场景）

1. **拿到新报告**：拍照或把 PDF/截图发给豆包，说「帮我解读并存档」。自动产出解读、把指标逐条入库、关联到对应人和报告，并在云盘留底。
2. **身体不舒服**：对豆包说症状（如「大女儿咳嗽鼻塞」），它会先做安全分诊，再把症状写进症状日记，必要时生成就诊建议。
3. **去看病**：看病前说「生成诊前简报」，看病中录音/记医嘱，看病后说「更新就诊记录并安排复查」。

# 三、日常记录

## 1. 检查报告（血常规、尿常规、生化等）

- 把报告发我即可，无需手动填表。系统会：识别异常项（↑↓）、标注重点关注、按类别归档，并判断是否需要复查。
- 报告状态有三种：**待解读 / 已闭环 / 需复查**。「需复查」的报告会进入「异常未闭环」视图，直到复查完成。

## 2. 症状日记

- 记录内容：症状、开始时间、严重程度、处置、照片/录音；可关联到对应就诊记录。
- 孩子急性症状优先记录，便于复诊时回顾病程。

## 3. 用药记录

- 记录药名、剂量、起止日期、状态（在服/已停）、关联就诊；「在服药物」视图只看当前在用。
- 新用药前可用「medication-check」技能核对相互作用、禁忌和重复用药。

# 四、周期管理

| 事项 | 频率 | 怎么做 |
|-|-|-|
| 月度小结 | 每月 1 日 | 对豆包说「月度小结」，自动汇总上月报告/异常/症状/用药/未闭环项 |
| 复查计划 | 按医嘱 | 就诊后自动生成检查计划，到期前与逾期会推送提醒 |
| 疫苗接种 | 按接种程序 | 在 vaccinations 表登记，目前为框架数据，请按接种本核对补全 |

# 五、长期管理

- **年度体检**：每年安排本人完整体检（含尿酸复查）；报告发我即自动解读并更新趋势。
- **年度复盘**：每年 12 月对豆包说「年度复盘」，回顾全年指标趋势、目标达成，制定下一年目标。
- **花粉季备药**：本人蒿草过敏，北方蒿草花粉季约 7 月下旬至 9 月，系统会在 7 月中旬提醒备药（抗组胺药、鼻喷激素、洗鼻）。
- **家族病史**：family_history 表目前为框架，请按实际补充直系亲属病史。

# 六、问诊全流程（重点）

| 阶段 | 动作 |
|-|-|
| **诊前** | 说「生成诊前简报」，自动汇总病史、既往异常、用药和要问医生的问题，可直接出示给医生 |
| **诊中** | 可录音（飞书妙记转文字），记下诊断、医嘱、开药和复查要求 |
| **诊后** | 说「更新就诊记录」，把诊断/医嘱/用药入库，自动生成复查计划并关联，形成闭环 |

# 七、默沙东大众版（科普）怎么用

- 权威、免费、面向大众的医学科普：[首页](http://www.msdmanuals.cn/home)、[症状索引](http://www.msdmanuals.cn/home/symptoms)、[健康话题](https://www.msdmanuals.cn/home/health-topics)，也有手机 App。
- 用法：对豆包说「结合默沙东讲讲 XX」，它会引用对应科普页，给出可靠解释并标明来源，用于理解疾病和症状，**不替代就诊**。

# 八、看哪里：视图与仪表盘

- **常用视图**：报告时间线、异常未闭环、待办检查、重点关注指标、在服药物、按人分组。
- **仪表盘「家庭健康总览」**：血尿酸趋势折线、异常未闭环数、报告总数、待办检查、在服药物、本月症状、指标类别分布，一屏看全局。
