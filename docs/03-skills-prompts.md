# 健康系统·6大智能技能（提示词库）

本文档是家庭健康管理系统的「智能操作层」。每个技能都包含：触发词、输入、标准流程、**可直接复制的提示词模板**、产出落库。两种用法：①在豆包对话里直接说触发词，豆包会按本流程执行；②把提示词模板复制到豆包自定义技能/智能体中固化。

# 技能总览

| 技能 | 一句话定位 | 典型触发 | 主要落库表 |
|-|-|-|-|
| report-reader | 报告解读存档一条龙 | 发报告截图/「解读存档」 | reports、lab_indicators、checkup_schedule |
| symptom-triage | 症状分级（红旗/居家/就医） | 「孩子发烧咳嗽」「我头疼」 | symptoms |
| medication-check | 药盒识别与用药核对 | 拍药盒/「这药能吃吗」 | medications |
| visit-brief | 诊前摘要 + 诊后纪要 | 「明天看病帮我准备」「刚看完病」 | encounters、checkup_schedule |
| health-review | 月度/年度健康小结 | 「月度小结」「年度复盘」 | 小结文档（可存云盘） |
| msd-reference | 默沙东大众版科普检索 | 「这病权威说法是什么」 | 科普引用/00-科普资料 |

# 技能1 · report-reader 报告解读存档

**定位：**收到任何体检/检验报告（血常规、生化、影像、体检汇总），自动识别、解读、结构化存档，并对异常项生成复查计划。

**输入：**报告截图/照片/PDF；必要时说明报告人（不说明则默认本人）、检测日期。

**标准流程：**

1. 识别报告：类型、机构、科室、检测日期、报告编号。
2. 在 reports 新建一条记录，状态先置「待解读」。
3. 逐个指标解析进 lab_indicators 长表：指标名称、数值（数字/文本）、单位、参考范围、参考下限/上限、异常状态、重点关注。
4. 按报告人年龄、性别匹配对应参考范围（成人与儿童不同），重新判定异常，不仅看报告上的箭头。
5. 对异常项分三级解读：明显异常 / 临界需关注 / 一过性波动；引用默沙东科普解释含义，**不做诊断**。
6. 对需复查项在 checkup_schedule 自动生成复查计划（含建议日期、提前提醒）。
7. 更新 reports 状态：已闭环 / 需复查 / 待解读；给出一段人话结论。

> **提示词模板（可直接复制）：**
> 你是我的家庭健康档案助手。请按以下流程处理我发的报告：①识别报告类型、机构、检测日期、报告号；②在 reports 建记录（状态=待解读）；③把每个指标解析进 lab_indicators 长表，含数值、单位、参考范围、异常状态、重点关注；④按报告人年龄性别重新核对异常，不要只看箭头；⑤对每个异常项说明含义（可引用默沙东大众版，附链接），区分明显异常/临界关注/一过性波动；⑥需要复查的在 checkup_schedule 生成计划和提醒；⑦更新 reports 状态，并用一段话告诉我结论和下一步。报告人是【】。不做诊断、不编造数据，无法识别的指标标"待核对"。

# 技能2 · symptom-triage 症状分级

**定位：**描述症状后，结合默沙东识别「红旗症状」，给出立即就医/尽快就医/居家观察的分级建议并记录。

**输入：**谁、症状、起病时间、持续时长、伴随症状、已做处理。

**标准流程：**

1. 补全关键信息（对象、症状、时间、伴随、严重程度）。
2. 查默沙东对应症状页，明确危险信号。
3. 对照红旗症状清单判断：命中→立即急诊/拨打急救。
4. 三分类输出：立即就医 / 24-48小时内就医 / 居家观察。
5. 居家观察给护理要点和"出现哪些情况必须就医"的红线。
6. 在 symptoms 记录一条（含症状、开始时间、严重程度、处置、状态）。

> **必须立即就医的红旗信号（示例，非全部）：**呼吸困难/嘴唇发紫、胸痛胸闷、意识模糊/抽搐/昏迷、大量出血/呕血/黑便、剧烈腹痛伴发热呕吐、严重过敏（喉头紧/面唇舌肿胀/全身风团）、婴幼儿精神萎靡/反复呕吐/喂养困难/明显脱水、孕妇腹痛出血。

> **提示词模板：**
> 你是我的家庭健康分诊助手。症状信息：对象【】、症状【】、开始时间【】、持续【】、伴随【】、已做处理【】。请：①查默沙东大众版对应症状；②先判断是否有红旗症状，命中就明确说"立即就医/急诊"；③否则分级为24-48小时内就医或居家观察；④居家观察给出护理要点和"出现哪些情况必须就医"的红线；⑤在 symptoms 记录一条。请用谨慎、客观的措辞，这是风险提示不是诊断，拿不准时建议就医。

# 技能3 · medication-check 用药核对

**定位：**拍药盒或说药名，识别成分、用法用量、相互作用、禁忌与过敏，生成用药时间表。

**输入：**药盒/说明书照片，或药名；用药人。

**标准流程：**

1. 识别药品通用名、成分、规格、剂型、生产厂家。
2. 说明适应症、用法用量、用药时间（餐前/餐后/睡前）。
3. 查该用药人在服药物，判断重复用药与相互作用。
4. 核对禁忌与过敏史（如本人蒿草过敏需关注交叉过敏）。
5. 核对年龄（儿童剂量、是否适用）。
6. 在 medications 建记录，生成服药时间表与提醒；疗程结束标记已停药。

> **提示词模板：**
> 你是我的安全用药助手。请识别我发的药盒/说明书：①给出通用名、成分、规格、剂型；②适应症和用法用量（餐前/餐后/睡前、剂量、疗程）；③用药人是【】，请对照其在服药物查重复用药和相互作用；④对照其过敏史/基础病查禁忌；⑤核对年龄是否适用、儿童剂量；⑥在 medications 建记录并生成服药时间表与提醒。信息不全或有风险时明确提示，不替我决定处方药使用。

# 技能4 · visit-brief 诊前摘要 / 诊后纪要

**定位：**就诊前自动生成一页纸病情摘要和问题清单；就诊后记录诊断、医嘱并转成用药与复查任务。

**诊前流程：**

1. 拉取就诊人近期症状、报告、在服药物、过敏史、家族史。
2. 生成一页纸诊前摘要：主诉、现病史、关键异常指标、用药与过敏。
3. 生成问题清单（要问医生的问题，含是否需要检查/复查、诊断、用药、注意事项）。
4. 提示就诊携带物（报告、医保卡、既往资料）。

**诊后流程：**

1. 在 encounters 记录：机构、科室、诊断、医嘱、关联报告。
2. 医嘱中的药物转 medications，复查转 checkup_schedule。
3. 更新相关 symptoms 状态；生成复诊提醒。

> **诊前提示词：**
> 我【时间】要带【对象】去【科室】看【问题】。请汇总 TA 的近期症状、报告异常、在服药物、过敏史和家族史，生成一页纸诊前摘要（主诉+现病史+关键指标+用药过敏），再列出要问医生的问题清单（诊断、检查、用药、复查、居家注意），并提醒要带的资料。
> **诊后提示词：**
> 刚带【对象】看完病，机构【】科室【】，诊断【】，医嘱【】。请：①在 encounters 建记录并关联报告；②把医嘱药物转 medications、复查转 checkup_schedule；③更新相关症状状态；④生成复诊提醒，并用人话总结回家后怎么做。

# 技能5 · health-review 周期小结

**定位：**按月/年汇总健康动态，看指标趋势、未闭环项、目标达成，给出下期重点。

**标准流程：**

1. 统计周期内：新增报告、异常指标及趋势、症状、用药、就诊。
2. 对重点指标（如尿酸）做趋势对比，说明变化方向。
3. 列出未闭环异常和逾期复查。
4. 对照 health_goals 看达成情况。
5. 给出下一周期重点行动（复查/备药/生活方式）。

> **提示词模板：**
> 请为【对象/全家】生成【月度/年度】健康小结：①统计周期内报告、异常指标趋势、症状、用药、就诊；②重点指标（如尿酸）做趋势对比说明方向；③列出未闭环异常和逾期复查；④对照年度目标看达成；⑤给出下一周期重点行动。数字请从 Base 实算，不要估算；输出可存档到云盘科普目录的小结。

# 技能6 · msd-reference 默沙东科普检索

**定位：**把症状、疾病、检查、药物的权威科普从默沙东大众版检索出来，规范引用并标注来源。

**默沙东入口：**

- 首页：http://www.msdmanuals.cn/home
- 症状索引：http://www.msdmanuals.cn/home/symptoms
- 健康话题：https://www.msdmanuals.cn/home/health-topics
- 常见问题：http://www.msdmanuals.cn/home/resourcespages/faqs

**标准流程：**确定检索词→检索大众版对应条目→提取定义、常见原因、症状、何时就医、居家处理→标注条目名称与 URL→声明"科普不替代诊疗"。

> **提示词模板：**
> 请帮我检索默沙东大众版关于【症状/疾病/检查/药物】的权威内容：①用通俗语言说明它是什么、常见原因、主要表现；②什么情况下需要就医、有哪些危险信号；③居家可做的处理；④附上默沙东条目名称和链接。只引用默沙东大众版，区分"科普"与"诊疗"，不替代医生诊断。

# 统一边界

> 六个技能均为**个人健康管理与健康科普辅助**，不构成诊断、处方或治疗建议。急症、重症、病因不明时优先就医；处方药的启动、停用、减量请遵医嘱。所有结论以医生面诊和检查为准，系统只负责记录、整理、提示与引用。
